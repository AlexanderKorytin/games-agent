# CLAUDE.md — игровой агент

Личный агент подбора игр Steam и Nintendo eShop. Устройство и решения — `docs/игровой-агент.md`.

## Общие

- Язык общения и текстов — русский; транслитерация английских слов запрещена. Имена команд,
  файлов и полей — как есть.
- Пользователь руками код не пишет и не запускает: всё делает ведущая среда.
- Качество важнее скорости. Своих пределов, потолков и магических чисел не заводить без согласия
  пользователя; нужен предел — назвать его вслух с ценой.
- Всё, что пишет в домашний каталог, переопределяется переменной окружения, и проверки уводят её
  во временный каталог (`agents/games/tests/conftest.py`).
- Ключи — только в `~/.config/games-agent/config.json` (права 600): ни в журнал, ни на страницу,
  ни в запрос модели.
- Раздел «Ограничения» карточки пишет только человек (кнопки «Нет», «Уже играл: не понравилась»).

## Карта кода

Где искать (`agents/games/` — агент, `mcp_servers/steam/` — сервер MCP и хранилище):

| Задача | Где |
|---|---|
| Окружение служб: каталоги данных, `MYHARNESS_*` | `agent_env.задать` — скрипт без него не видит карточку вкуса |
| Задания дня, недели, месяца, «регион»; замки | `jobs.запустить`, `день`, `неделя`, `месяц`, `_отобрать`; `ПАЧКА`, `ОЖИДАНИЕ_ЗАМКА_С` |
| Источники магазинов для заданий | `jobs.Магазин` |
| Суд местной моделью: пачкой и по одной | `judge.судить_пачкой`, `запрос_пачки`, `разобрать_пачку`, `модель_пачки`; `judge.судить`; `jobs.Судьи` |
| Инструкции модели | `profiles/отбор-игр-mcp.md` (пачка), `отбор-игр.md` (одна), `игровой-советник.md` (разговор) |
| Вкус и запреты из карточки | `taste.вкус`, `критерии`, `запреты_по_имени` |
| Советник (разговор), пересмотр вкуса | `advisor.модель`, `разрешения`, `текст_пересмотра` |
| Похожие игры из истории (RAG) | `similar.Индекс`, `similar.блок`; векторы `embedder.py` |
| Местные модели: выбор, загрузка, вариант 32 768 | `models.выбрана`, `скачать`, `вариант_для_разговора`, `ВАРИАНТ` |
| Смена регионов | `regions.пересобрать`, `jobs.смена_региона` |
| Веб и страница | `web.py` (пути `/api/*`), `index.html` |
| Значок в строке меню | `menubar.py` |
| Установка и службы launchd | `deploy/установить.sh`, `deploy/служба.plist.in` |
| Хранилище SQLite, схема, транзакция | `mcp_servers/steam/games_db.py`: `открыть`, `транзакция` |
| Инструменты MCP | `mcp_servers/steam/server.py` |
| Steam: поиск, игра, страна | `steam_store.найти_с_отзывами`, `steam_store.игра`; профиль — `steam_account.py` |
| eShop: зоны Америки и Европа | `eshop.py` — единая точка (`витрина`, `игра`, `цены`, `найти_в_steam`); `eshop_store.py`, `eshop_eu.py` |
| Оценка Metacritic, минимум цены | `metacritic.py`, `itad.py` |
| Ключи | `secrets_store.py` (файл `~/.config/games-agent/config.json`) |

- `cd agents/games && uv run -q pytest -q`

## Ближайшая работа

- Облачные поставщики на выбор: Claude (SDK `anthropic`) и OpenAI рядом с DeepSeek — правка
  `myharness` (задача 19 челленджа).
- Подбор местных моделей для выбора при установке: замер на сценариях опроса и отбора (задача 20).
- Уведомления от имени агента, а не «Редактора скриптов»; подпись Apple Developer ID.
- eShop Японии — отложено: каталог есть, но без порядка популярности.
- Живьём не проверены: ключ IsThereAnyDeal, «Уже играл», сверка раз в полгода, догоняющий запуск
  после выключения Мака, установка на чистый Мак; eShop — скидка со сроком (`до`), пары Steam и
  eShop в живой выдаче, смена зоны Америки ↔ Европа на настоящих данных; суд пачкой через MCP на
  настоящем задании недели (месяц проверен); страна профиля Steam на ключе (`loccountrycode`).

## Координатор: проект

Подтверждено пользователем 2026-10-19.

- **Репозитории:** один — `~/projects/games-agent`: `agents/games/` — агент (задания, веб, страница),
  `mcp_servers/steam/` — сервер MCP и хранилище. `myharness` — чужая библиотека, по замыслу не
  меняется.
- **Требования:** своих `openspec/specs` нет; их роль играет дизайн `docs/игровой-агент.md`. Стадии
  Spec — одной строкой «требований в проекте нет», решения пишутся в дизайн.
- **Документация:** при изменении поведения — `docs/игровой-агент.md`, `docs/состояние-игровой-агент.md`,
  `README.md`, `agents/games/README.md`, карта кода в этом файле.
- **Проверки:** `cd mcp_servers/steam && uv run -q pytest -q`; `cd agents/games && uv run -q pytest -q`.
  Сценарий приёмки: перезапуск веба (`launchctl kickstart -k gui/$(id -u)/local.games-agent.web`),
  страница в браузере на настоящей установке, нужная вкладка.
- **Агент безопасности:** отдельного нет; при риске — проверяющий на Opus с правилами о ключах выше.
